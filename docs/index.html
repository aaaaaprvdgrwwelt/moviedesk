MovieDesk

Ein Dateimanager für Filme und Serien: Ordner einlesen, Metadaten von TMDb/OMDb/TheTVDB holen, nach Vorlage umbenennen. Gebaut, weil Sonarr und tinyMediaManager für eine kleine private Sammlung mehr Aufwand machen, als sie einem abnehmen.

Auf GitHub ansehen Installation Metadaten-Quellen
Status: nutzbar. Entwickelt und getestet unter Linux. Windows und macOS sollten laufen (reines Qt/Python), sind aber nicht manuell getestet — die automatisierte Testsuite läuft dort in der CI.

Was es kann

Oberfläche auf Deutsch und Englisch, umschaltbar im laufenden Betrieb.

Scannen

Erkennt gängige Szene-Konventionen (S01E05, 1x05), Mehrfach-Episoden wie S01E01E02 vollständig und Anime-Nummerierung ohne Staffelangabe. Samples/Trailer fliegen raus, ohne echte Episodentitel mit „Extra“ im Namen zu verwechseln.

Automatisch zuordnen

Bewertet Kandidaten nach Titel und Jahr. Unsichere Treffer bleiben markiert, statt falsch automatisch zugeordnet zu werden — Nachtragen per Doppelklick oder direkt per TMDb-/IMDb-Link.

Gezielt rescannen

Rechtsklick auf einen Film oder eine Serie → nur diesen einen Ordner neu einlesen, statt jedes Mal die ganze (oft riesige) Bibliothek zu durchsuchen.

Sammlungen & fehlende Teile

Filmreihen gruppieren sich automatisch. Bei ausgewählter Sammlung oder Serie zeigt „Fehlende Teile“, was laut TMDb noch aussteht.

Umbenennen nach Vorlage

Vorschau vor jeder Änderung, nichts wird vorher auf der Platte angefasst. Eigene Vorlagen für Filme und Serien, inklusive Mehrteiler-Platzhalter.

NFO & Untertitel

Kodi-/Jellyfin-/Plex-kompatible .nfo-Dateien auf Wunsch, Untertitel-Download über OpenSubtitles in den konfigurierten Sprachen.

Bilder

Filmraster mit Metadaten-Panel im laufenden Betrieb.

Installation

Fertige Pakete für Windows/macOS unter Releases — unsigniert, deshalb beim ersten Start je einmal „Trotzdem ausführen“ (Windows) bzw. Rechtsklick → Öffnen (macOS) bestätigen. Aus dem Quelltext (Linux und alle anderen) reicht Python 3.10 oder neuer:

git clone https://github.com/aaaaaprvdgrwwelt/deskkit.git
git clone https://github.com/aaaaaprvdgrwwelt/moviedesk.git
cd moviedesk
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

Starten

./moviedesk.sh            # oder: .venv/bin/python -m moviedesk
./install-desktop.sh      # Eintrag im Anwendungsmenü anlegen (Linux)

Metadaten-Quellen

Alle vier optional, einzeln unter Einstellungen → Quellen/Untertitel abschaltbar. API-Keys landen im System-Schlüsselbund statt im Klartext.

QuelleWofürKey
TMDbTitel, Jahr, Poster, Genres — Filme und Serien. Ohne diesen Key funktioniert die automatische Zuordnung praktisch nicht.ja, kostenlos
TheTVDBAlternative für Serien mit guter Staffelstrukturja, kostenlos
OMDbergänzt IMDb-Rating, hilft bei IMDb-Link-Zuordnungja, kostenlos
OpenSubtitlesUntertitel-Downloadja, kostenlos

Umbenennen-Vorlagen

Frei einstellbar unter Einstellungen → Umbenennen. Ein / legt eine neue Ordnerebene an.

Filme:  {title} {year} {ext}
Serien: {series} {year} {season} {episode} {episode_end} {episode_title} {ext}

{year} ist das Jahr der Erstausstrahlung, {episode_end} nur bei Mehrteilern wie S01E01E02 belegt (sonst leer).

Die Bibliothek ist die Quelle der Wahrheit. Anders als bei ComicDesk (ComicInfo.xml direkt in der Datei) kennen Videodateien kein verbreitetes eingebettetes Metadatenformat — Zuordnungen leben deshalb in einem SQLite-Index, der beim Umbenennen automatisch mitgeführt wird.
